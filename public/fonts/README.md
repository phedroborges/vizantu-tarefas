The application uses Mona Sans. The two `vizantu-pdf-*.ttf` files are static
instances of the existing `mona-sans-latin.woff2`, at weights 400 and 600,
converted with FontTools for jsPDF. Their font family names are changed to
Vizantu PDF in accordance with the Reserved Font Name clause of the bundled
SIL Open Font License. The original outlines and copyright notices are retained.

The PDF logo at `../brand/vizantu-pdf.png` is a transparent, 1400px-wide render
of the canonical `../brand/vizantu-dark.svg`.
